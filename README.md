File Integrity Checker – Project Description
So basically, when we store files on our computer, we always want to make sure that no one has changed or tampered with them without our knowledge. This is what we call file integrity – it simply means checking whether a file is still the same as it was before, or if something has been modified, deleted, or added.
for example – imagine you write something on a paper and seal it. Later, you open it and want to confirm nobody changed what was written inside. File integrity does the same thing, but for digital files.

Let's know how its works ?
The idea is pretty simple. Every file has its own unique "fingerprint" called a hash value. This is a long string of letters and numbers generated by a mathematical algorithm. If even a single character inside the file changes, the hash completely changes too.
In this project, I used the SHA-256 algorithm (from Python's hashlib library) to generate these hash values. The program reads each file in small parts (chunks of 4096 bytes) so that even large files can be handled without slowing down the system.

What I Built in the Code......

I divided the whole program into 6 steps/functions, which makes it clean and easy to understand:

1. calculate_file_hash() – This function opens any file and calculates its SHA-256 hash value.
2. scan_folder() – Scan the entire folder (and subfolders too, using os.walk) and collects the hash of every file found.
3. save_hash_records() – After scanning, all the hash values are saved into a hash_records.json file. This acts like a "baseline" or the original record.
4. load_hash_records() – When we want to check integrity later, this function loads back the saved hash records from the JSON file.
5. check_integrity() – This is the main checking function. It compares the current hash values of files with the saved ones and reports:

#[ok] – file is unchanged

#[modified] – file has been changed

#[new file] – a file was added

#[deleted] – a file was removed


6. main() – This is where the user interacts with the program. It shows a simple menu where you either scan and save (option 1) or check integrity (option 2).
